El viaje de un evento

Cada evento deja un rastro de luz

Tu aplicación sabe en todo momento dónde está cada dato, desde que sale hasta que se procesa.

01
sent

Aceptado

Luminis recibe el evento, le asigna un identificador y te lo confirma al instante.

02
delivered

Entregado

Llega a cada dispositivo del destino, incluso si se conecta más tarde.

03
seen

Procesado

El receptor confirma que lo usó y el emisor recibe el acuse al momento.

04
desaparecido

Expirado

Si nadie lo reclama dentro de la retención del plan, se descarta y se avisa.

Para desarrolladores

Tres pasos y tus datos ya están viajando

Un endpoint WebSocket, eventos JSON libres y una API REST para publicar desde tu backend. Sin servidores que mantener.

  1. Crea tu API keyDesde el panel, con los permisos que necesites.
  2. Abre el socketConecta a /socket con tu llave y el identificador del dispositivo.
  3. Publica y escuchaEnvía cualquier JSON y recibe message, delivered y seen.

Preguntas

Respuestas antes de encender

¿Qué tipo de datos puedo enviar?

Cualquier JSON o texto: lecturas de sensores, coordenadas, estados, precios, comandos o mensajes. El único límite es el tamaño máximo de evento de tu plan.

¿Qué cuenta como petición?

Cada evento enviado por el socket y cada llamada a la API pública de Luminis. Los pings y confirmaciones de procesado no consumen tu plan.

¿Qué pasa si llego al límite?

Si tu plan no permite adicionales, las nuevas peticiones se rechazan con el error LIMITE_PETICIONES. Si los permite, se cobran por cada mil peticiones extra.

¿Cómo funciona la cola offline?

Los eventos para destinos desconectados esperan el tiempo de retención del plan y se entregan al reconectarse. Si expiran, el emisor recibe el evento desaparecido.

¿Puedo conectar varios dispositivos?

Sí. Un mismo usuario o dispositivo puede tener varias sesiones abiertas y todas reciben sus eventos, dentro del límite de conexiones simultáneas.

¿Existen planes sin límites?

Sí. Algunos planes tienen peticiones, conexiones o tamaño de evento ilimitados. Los verás marcados con el símbolo ∞.
